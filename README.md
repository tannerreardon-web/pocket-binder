# Pocket Binder

A digital trading card binder that runs in the browser. Open it on an iPhone in Safari, tap Share, then Add to Home Screen to install it like an app.

- Binders are saved on each device under a username. Anyone on the device can view a binder; its PIN is needed to change it.
- Binders published with the site live in `users/<username>.json` and load the first time that username is opened on a device.
