Scan binder pages

Take a straight-on photo of each binder page, one page per photo. Pocket Binder cuts each pocket out as the card's picture, and an AI reads the name, set and number. Nothing is sent anywhere until you choose how to identify the cards.

File format 
{
  "binder": { "name": "Trade Binder", "color": "#9b1c2c", "cols": 3, "rows": 3 },
  "cards": [
    { "name": "Card name", "set": "Set name", "number": "025/198",
      "rarity": "Holo Rare", "game": "", "notes": "",
      "page": 1, "row": 1, "col": 1,
      "image": "data:image/jpeg;base64,…" }
  ]
}

Everything but name is optional. Position cards with page/row/col or a zero-based slot; cards without a position fill the next empty pockets. Pictures must be embedded as data URLs.

Get card images

Pocket Binder looks up each card's official picture by its name, set and number, then saves it to the card. Pictures come from free card databases: the Pokémon TCG API and TCGdex for Pokémon, Scryfall for Magic: The Gathering, and YGOPRODeck for Yu-Gi-Oh!. Sports cards and other games aren't covered, so those keep their scans or placeholders. If you've added a Scrydex key in Customize, Pokémon cards can use Scrydex too.
